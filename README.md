# Structural Calculations

A responsive static website for structural engineering calculations, projects, tools, and resources.

## Deploy free with GitHub Pages

1. Create a free account at GitHub.
2. Create a repository named `YOURUSERNAME.github.io`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open **Settings → Pages** and enable deployment from the main branch.
5. Your website will be available at `https://YOURUSERNAME.github.io/`.

## Customize

- Replace the placeholder email in `index.html`.
- Change the GitHub link to your repository.
- Add your calculation files and project pages.
- Replace the sample calculation cards with your actual footing, beam, column, slab, etc. tools.

The site is static HTML/CSS/JavaScript, so no paid hosting or database is required.
